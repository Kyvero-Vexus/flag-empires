** Entity Prefixes
- POL: polity
- PER: person
- LOC: location
- EVT: event
- TXT: text witness
- RIT: ritual

** Identifier Rules
Global entity IDs: FE-<TYPE>-<BOOK>-<NNN>
Examples:
- FE-POL-B1-003
- FE-PER-B2-119
- FE-LOC-B3-041

Event IDs are always paired with canonical chapter IDs.

** Dynastic Line Model
Dynasty record fields:
- House Name
- Banner Color Rite
- Founding Claim
- Legitimation Texts
- Succession Method
- Catastrophic Breaks

** Annal Reliability Classes
| Class | Name         | Meaning |
|-------+--------------+---------|
| R1    | Seal-Certain | Multiple sealed archives concur |
| R2    | Court-Strong | Court copies align; provincial variants minor |
| R3    | Field-Mixed  | Military logs conflict with civic rolls |
| R4    | Witness-Torn | Eyewitness testimony contradictory |
| R5    | Ash-Lost     | Survives only through later quotation |

** Timeline Schema
Each timeline row:
- Year Code
- Event Canon ID
- Locale ID
- Principal IDs
- Reliability Class
- One-line synopsis

** Ritual Schema
Ritual entries must state:
- Officiant class
- Required objects
- Gesture order
- Spoken formula
- Political meaning

** Dispute Annotation Protocol
When records disagree, append:
- Dispute tag: DS-<NN>
- Positions A/B/C
- Source text IDs
- Adjudication note by Seal-Keeper

** Manuscript Assembly Rules
The complete volume concatenates in order:
1. Style Bible
2. Canon Schema
3. Master Outline
4. Book I
5. Book II
6. Book III

No section may remain empty.
